# furgo.mx

Plataforma CRM SaaS multi-sucursal para la gestión integral de peluquerías caninas y centros de estética de mascotas.

## Estructura del Proyecto

- `backend/`: API FastAPI y servicios de servidor.
- `frontend/`: Aplicación web cliente (CRM operativo y Consola Super Admin).
- `landing/`: Landing page comercial de furgo.mx (servida en `/landing`).

## Versión Actual

- `v0.5.0` - Plataforma multi-tenant furgo.mx con panel operativo, consola Super Admin y landing comercial.
